# Context engineering rules

- Load harness knowledge progressively from the relevant workspace manifest.
- Do not duplicate canonical truth across context, rules, specs and ADRs.
- Longitudinal history must not imply proportional serving-context growth.
- Not every interaction deserves the same cognitive budget.
- Reflex, Contextual and Deliberative are Conversation routing lanes; lane implementation remains internal to Conversation.
- Expensive reasoning, retrieval and tools should be escalated only when the turn requires them.
