# Onboarding workflow context

Onboarding belongs to each participant's private account. Elo selection is account-local and never grants or merges conversation, memory or permissions. The product conversation is voice-first; onboarding form fields are not a second conversation mode.

Load `.agents/rules/008-product-safety-and-privacy.rule.md` for account/session work and `.agents/skills/frontend-ui-engineering/SKILL.md` plus `.agents/skills/accessibility/SKILL.md` when changing forms or authentication UI.
